About me

I am Jerome Bernas, a third-year Bachelor of Science in Information Technology student at Filamer Christian University. I graduated from Commissioner Luis R. Asis National High School in 2024, where I studied in the ICT strand. Through my studies, I have developed an interest in programming, database management, web development, and creative digital solutions.

Through academic projects, I have worked on different parts of a system. In our Hospital Management System, I worked as the backend programmer, creating the MySQL database and writing the Python code. I also designed a tourism website interface using HTML and CSS, and I built the face scanning feature, including game-like visual effects, in a group project.

I participated in the Government Internship Program (GIP) at the Capiz Provincial Capitol in 2025 and 2026, completing one month of internship in each year. During these experiences, I assisted with organizing information, preparing office documents and presentations, and participating in office activities. Outside of coding, I enjoy video editing and digital design, allowing me to combine creativity with technology. I value teamwork, communication, and problem-solving as I continue developing my skills and pursuing a career in the IT industry.

Flagship project 1 · Information System · Academic Project

Hospital Management System

PythonMySQLHTMLCSSJavaScript
Purpose
An academic project designed to help organize hospital-related information and records.
The problem
Managing hospital records by hand makes information hard to organize, find, and keep accurate.
Architecture and tech stack
Frontend: HTML, CSS, JavaScript. Backend: Python. Database: MySQL. We used these technologies because they were part of our course and are beginner-friendly. MySQL stores hospital information in organized tables, and Python handles the system’s logic.
My individual contributions
I worked as the backend programmer. I designed and created the MySQL database used to store the system’s records, wrote the Python code for the system’s backend, and connected the Python backend to the MySQL database.
Results and testing
I tested the backend during development. The Python code connected to the MySQL database, and the system was able to store and retrieve hospital records. Errors found during testing were fixed by our group.

Flagship project 2 · UI Design · Prototype

Tourism Management System: UI Design Prototype

HTMLCSS
Overview
A tourism management website interface designed to present tourism-related information through a structured and visually engaging layout. The project focused on front-end development, page organization, visual presentation, and user interface design using HTML and CSS. It was created during my second year and is a front-end prototype with no booking, payment, or database functions.
The problem
Tourism information is easier to use when it is organized in a clear, accessible, and visually structured website.
Design approach and tech stack
HTML and CSS, front-end layout, visual hierarchy, image placement, and user interface design.
My individual contributions
I designed and coded the website pages using HTML and CSS. My work included the page layout, the navigation menu, and a booking page interface. The booking page is for display only and does not have working functions.
Results and testing
The project is a visual prototype. The pages were viewed in a web browser, and the layout, navigation menu and images displayed as designed. The booking page is for display only and does not have working functions.

PORTFOLIO — HOW TO USE
======================
Open index.html in your browser to run it (double-click). No install needed.

1) PUT YOUR PHOTOS (any of .jpg .jpeg .png .webp — just keep the file name)
   images/profile.jpg                          your 1:1 profile photo
   images/projects/hospital-management.jpg     Hospital Management System screenshot
   images/projects/tourism-ui.jpg              Tourism UI Design screenshot
   images/projects/face-tracking.jpg           Facial Recognition project
   images/projects/postgresql-database.jpg     PostgreSQL project
   images/certificates/cert-1.jpg, cert-2.jpg, cert-3.jpg   certificates

2) PUT YOUR PDFs in the docs folder (exact names):
   docs/resume.pdf
   docs/cover-letter.pdf
   docs/developer-guide.pdf

3) EDIT TEXT: open index.html in VS Code and search for "[" — every [bracket]
   is a placeholder to replace with your real information.
   Also replace href="#" on LinkedIn, GitHub, Live demo and Repository buttons.

4) MORE CERTIFICATES: copy one <button class="cert"> block in index.html and
   change its data-img to images/certificates/cert-4 (then add cert-4.jpg).

5) CHECK: press F12 > Console. It tells you how many placeholders/links remain.

6) PUBLISH FREE: upload this whole folder to GitHub Pages, Netlify or Vercel.
   Keep index.html, css, js, images and docs together.
